# Oyster's LAB — Gastronomic Guide

Интерактивный гид по устрицам и блюдам ресторана Oyster's LAB. Приложение работает как одностраничный сайт (SPA) на чистом HTML/CSS/JavaScript без сборки.

## Возможности
- Просмотр карточек 12 устриц с описанием, вкусовым профилем, происхождением и интересными фактами
- Меню блюд с категориями (тако, хот-доги, мидии, морепродукты, плато, запечённые устрицы, закуски, десерты)
- Викторина для подбора устрицы по вкусу (6 вопросов)
- Сравнение двух устриц по характеристикам
- Поддержка трёх языков: русский, румынский, английский
- Мобильная адаптация, тёмная тема

## Запуск
Просто откройте файл `index.html` в браузере или разместите на любом статическом хостинге (GitHub Pages, Netlify, Vercel).

## Структура
- `index.html` — вся разметка, стили и логика в одном файле
- `README.md` — описание проекта

## Технологии
- HTML5, CSS3 (Flexbox, Grid, CSS-переменные)
- Vanilla JavaScript (ES6+)
- Google Fonts (DM Sans, Cormorant Garamond)
